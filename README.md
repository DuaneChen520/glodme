
# 华安黄金ETF(518880) 日内做T系统

一个专为华安黄金ETF（518880）设计的日内T+0量化交易系统，提供策略回测、实时监控、风险管理等完整功能。

## 功能特性

- 📊 **策略回测**: 在历史数据上测试策略表现
- 📈 **实时监控**: 实时查看价格走势和交易信号
- 📋 **多技术指标**: 布林带、RSI、MACD、移动平均线等
- 💰 **风险管理**: 止损止盈、仓位控制、回撤控制
- 🎨 **Web界面**: 基于Streamlit的交互式可视化界面
- 🔧 **可定制化**: 灵活配置策略参数



## 核心模块说明

### 1. 数据获取 (data_fetcher.py)

负责获取历史和实时行情数据：
- 支持AKShare数据源
- 提供模拟数据作为备选方案
- 支持历史日线和日内分钟级数据

### 2. 策略模块 (strategy.py)

核心策略逻辑：
- 基于布林带和RSI的均值回归策略
- 多指标综合判断买卖信号
- 内置止盈止损机制
- 完整的回测功能

### 3. 风险管理 (risk_manager.py)

风险控制功能：
- 交易成本计算
- 仓位限制
- 每日亏损限制
- 最大回撤控制

### 4. Web界面 (app.py)

交互式监控界面：
- 实时价格走势
- 策略参数配置
- 回测分析
- 风险指标监控
- 交易记录查看

## 策略原理

本系统采用**均值回归策略**，核心逻辑：

1. **价格偏离度**: 当价格偏离布林带轨道时，认为会向均值回归
2. **RSI确认**: RSI超买超卖辅助判断
3. **均线交叉**: 短期均线与中期均线交叉确认趋势
4. **风控保护**: 止损止盈和仓位管理控制风险

## 使用流程

1. **参数配置**: 根据市场情况调整策略参数
2. **历史回测**: 在历史数据上验证策略
3. **模拟交易**: 在模拟环境中运行观察
4. **实盘监控**: 实时监控信号，辅助决策
5. **分析优化**: 根据表现持续优化策略
